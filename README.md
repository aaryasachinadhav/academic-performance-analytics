# Academic Performance & Exam Analytics System

A self-designed academic planning, tracking and performance
analytics system built in Google Sheets and used throughout
Grade 12 (2025–26).

## Overview

I originally built this system to manage my own Grade 12
academic preparation. Over time, it evolved into an interconnected
system for planning, topic-level preparation tracking, revision,
exam management, performance analysis and visualization.

The system follows:

PLAN → PREPARE → REVISE → TEST → MEASURE → COMPARE → ANALYZE → IMPROVE

## Key Components

- Study planning
- Topic-level preparation tracking
- Revision tracking
- Examination tracking
- Predicted vs. actual performance
- Marks calculations
- Performance dashboards
- Data visualization

## Tools

- Google Sheets
- Spreadsheet formulas
- Data validation
- Conditional formatting
- Charts & visualization
- Structured tables
